How this demo works

This page runs the project's actual Python code (src/) in your browser with Pyodide. Each tick the radar adds noise, the Kalman tracker estimates every asteroid, the rule engine checks for danger, minimax picks a tactic, A* plans a path and the CSP decides whether a shot is safe. The panels show the explanation the pilot itself produces.

Team: Ashutosh Diwan, Tanishq Ajmeria, Vithul P Rajeev, Himanshu Kumar.

Keys: Space pause · R restart · N new seed · G grid
